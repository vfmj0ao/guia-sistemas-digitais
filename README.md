# Guia de estudo — Introdução a Sistemas Digitais

Material de revisão para a disciplina **Introdução a Sistemas Digitais** (UFMS/CPAN), compilado a partir das listas e das aulas do professor Murilo.

O guia abre no navegador — inclusive no celular — sem instalar nada.

## Conteúdo

- Mapa da prova (o que mais cai)
- Analógico × digital
- Binário e pulsos
- Portas lógicas
- Blocos digitais
- CIs e PLDs
- Arduino (bloco mais cobrado)
- Treino rápido com perguntas e respostas

## Como usar

Abra `site-vercel/index.html` no navegador.

No computador: **Ctrl+P** → *Salvar como PDF* se quiser imprimir.

## Stack

HTML, CSS e JavaScript puros. Publicado na Vercel a partir da pasta `site-vercel`.
